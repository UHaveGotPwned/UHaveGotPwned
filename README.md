### `# whoami`

Hello everybody, I'm UHaveGotPwned, but you can call me **π**.

I work as a **C++ / Rust / TypeScript** developer, and I spend my free time deep in offensive security — hacking, malware analysis, and writing code that probably shouldn't exist but is fun to build anyway.

I'm into both sides of pentesting — server-side and client-side — with more hands-on mileage on the client side. Still grinding on both, it's all reps and time.

When it comes to malware, my thing is the **analysis** side: understanding how something is built, what techniques it uses, and *why* it works. That's really what hacking is about for me — understanding systems deeply enough to find what everyone else walks past, and thinking outside the box to get there.

I also build malware for fun / research — no better way to understand defenses than to try to break them yourself.

> If you don't know how something breaks, you don't really know how it works.
